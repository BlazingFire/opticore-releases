# OptiCore Releases

Windows installers for **OptiCore**, an offline management suite for local ISPs, fiber and cable TV operators.

- Download the latest `OptiCore-Setup-x.y.z-x64.exe` from [Releases](../../releases).
- Verify it against `SHA256SUMS.txt`.
- Requires Windows 10/11 x64 and 4 GB RAM. The database is bundled.

License keys are issued by your OptiCore vendor (Rs 3,500 / year per installation).
